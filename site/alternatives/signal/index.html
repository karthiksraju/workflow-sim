How it works

Real code. Modeled world. A verdict you wrote.

01

Your workflow, unchanged

Point it at the asyncio or Celery code you already ship. Every run starts in a fresh worker process.

02

Failures on your schedule

You model the services it talks to. Time is virtual, so a lost response at second 0 and a retry at second 2 take no real time.

03

Checks on what's left behind

You write the assertions about final state. PASS means they held in that modeled run. It doesn't write fixes or certify production.
